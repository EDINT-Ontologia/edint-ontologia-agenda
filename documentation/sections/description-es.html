En la Figura 1 se muestra el modelo conceptual de la ontología con sus clases y relaciones (propiedades de objeto).

El vocabulario reutiliza términos del vocabulario schema.org para la representación de los eventos y la documentación asociada. También se reutiliza el vocabulario de Dirección Postal y el vocabulario de Territorio que contiene las divisiones administrativas para representar el ámbito de un evento, por ejemplo un distrito o un barrio. El concepto principal de este vocabulario es el de un evento que tiene lugar en una ciudad. El lugar en donde se realiza el evento puede ser un equipamiento de la ciudad tal como el edificio del ayuntamiento, un centro cultural, etc. Un evento tiene una dirección que puede estar normalizada utilizando las propiedades de la clase esdir:DireccionPostal. Adicionalmente, en este vocabulario se han utilizado varios esquemas de conceptos SKOS para representar el tipo de evento, la modalidad de asistencia (presencial, en línea o mixto) o el estado de un evento (programado, cancelado, aplazado o reprogramado).
