Figure 1 shows the conceptual model of the ontology with its classes and relationships (object properties).

The vocabulary reuses terms from the schema.org vocabulary for the representation of events and the associated documentation. The vocabulary Postal Address is reused, and also the vocabulary Territory which contains administrative divisions to represent the scope of an event, for example, the municipality in general or a specific district or neighborhood The main concept of this vocabulary is that of an event that takes place in a city. The place where the event occurs can be a city facility such as the town hall, a cultural center, etc. An event has an address that can be normalized using the properties of the class esdir:DireccionPostal . Additionally, this vocabulary uses several SKOS concept schemes to represent the type of event, the attendance modality (in-person, online, or hybrid), or the status of an event (scheduled, canceled, postponed, or rescheduled).
